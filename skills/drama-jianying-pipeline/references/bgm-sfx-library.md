# 短剧 BGM 与音效库（分类、情绪关键词、用法）

本文件是剪辑时选 BGM 和音效的**索引**，不附带任何音频文件。曲名是短剧圈常用热门 BGM 的检索名，用于在剪映「音乐」库、用户自有素材或已获授权的曲库里搜索；分类和情绪标签是使用定位，**每次上轨前必须实际试听确认**情绪、段落和版权标记，听感与标签不符时以试听为准并回写本表。

## 一、版权与来源（先于一切）

- 只用三类来源：剪映内置「音乐/音效」库（按剪映与发布平台条款使用，注意曲目上的“可商用/仅限抖音”等标记）、用户提供且有权使用的文件、明确许可（如 CC BY，需署名）的曲库。
- 不从网盘、视频站扒音轨，不把“能搜到/能播放/有缓存”当作有使用权。
- 每集在 剪辑单.md 的音轨表记录：曲名、来源（剪映库/用户文件/许可曲库）、使用区间、版权标记或署名。
- 剪映库内同名曲有多个版本（原版/DJ/剪辑版/卡点版）时，记录实际采用的版本。

## 五、音效三层架构（爆款短剧音效组接）

剪映音效库检索词写在括号里；同类可替换。

### 1. 基础拟音层：贴合画面动作，还原现实感
关门、开门、脚步、敲门、耳光、高跟鞋、汽车鸣笛、水杯碰撞、翻书、衣物摩擦、拔剑/收剑、落座、纸张、钥匙。
- 与画面动作帧对齐（落点 ±1 帧），音量服从对白。
- 只给“看得见、听得出”的动作配，不给每个镜头都加。

### 2. 情绪强化层：短剧爽感核心
主力是**重音音效**。人物表情、剧情发生转折时，**在反应出现约 0.2 秒后**跟上重音，让观众先看到再被“砸”一下；同一转折可以叠第一重音＋第二重音（短促＋长尾）。
- **震惊错愕：** 耳鸣、嗡鸣（检索：耳鸣、头晕嗡鸣）
- **紧张悬疑：** 低频轰鸣＋心跳（检索：心跳、紧张、悬疑氛围长音）
- **尴尬场面：** 鸦雀无声、空白音效（检索：乌鸦飞过、尴尬），或直接把音乐和环境抽空
- **转折 / 反转：** 重音、震撼转场音效、影视“嗒”转场
- **字幕 / 字卡包装：** 文字破碎冲屏、闪光字幕刀光剑影、高音闪光转场、综艺清脆敲声、解密类综艺悬疑滑音
- **钱 / 奖励 / 系统：** 金币散落音效、叮咚、系统提示音
- **吊胃口 / 结尾：** 紧张（马上有大事要发生了）、悬疑滑音；集末接黑场或模糊闭幕

### 3. 环境空间层：全程铺底，塑造空间感
按场景全程铺背景声：风声、鸟鸣、车流噪音、人群嘈杂、雷雨、室内空调底噪、山林、宫殿空旷混响。
- 音量低（通常比对白低 18–25 dB），场景切换时随画面换底，跨切点做 0.3–0.5 秒交叉淡化，避免底噪突然断。

### 组接原则
- 三层同时存在但不打架：对白 > 情绪强化 > 拟音 > BGM > 环境。
- 一个剧情节拍只放一个“主重音”；重音太密会失去冲击。
- 音乐的起落点卡剧情节拍：铺垫段可提前 1–3 秒淡入，爆点卡第一拍，煽情段在台词后留 0.5–1 秒余韵。
- 尴尬、震惊、欲言又止时，**抽掉音乐**往往比加音效更有力。

## 六、本表的维护

- 新剧开剪先按“题材 + 每场情绪关键词”从本表选 2–4 首主 BGM，写进 项目剪辑设定.md 的“音乐方向”。
- 实际使用后，把曲名、版本、来源与听感修正补回本表或本剧设定。
- 新增曲目同样填写：情绪关键词、适配题材、典型用法；不确定的标“待试听”。
